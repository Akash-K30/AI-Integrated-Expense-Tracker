# 💸 AI Expense Tracker (PERN + Gemini)

A full-stack Personal Expense Tracker built with the PERN stack (PostgreSQL, Express, React, Node.js) and integrated with Google's Gemini AI. The app allows users to log expenses, view monthly summaries, and receive personalized, actionable financial advice generated by Gemini based on their real spending data.

## 🌟 Features

*   **User Authentication:** Secure JWT-based login and signup.
*   **Data Isolation:** Each user only sees and analyzes their own data.
*   **Monthly Budgeting:** Filter expenses by month and year.
*   **AI Financial Advisor:** Uses the `gemini-2.5-flash` model to analyze your category spending and provide custom savings tips.
*   **Modern UI:** Responsive, clean interface built with React and Tailwind CSS v4.
*   **Production Ready:** Configured for deployment on Vercel (Frontend) and Render (Backend) with Supabase (Database).

## 🏗️ Architecture

*   **Database:** PostgreSQL (hosted on Supabase)
*   **Backend:** Node.js, Express.js, `pg` (PostgreSQL client)
*   **Frontend:** React, Vite, React Router, Tailwind CSS
*   **AI Integration:** `@google/genai` (Google Gen AI SDK)

## 🚀 Local Development Setup

### Prerequisites
*   Node.js (v22 or above recommended)
*   A Supabase account (or local PostgreSQL instance)
*   A Google Gemini API Key (from Google AI Studio)

### 1. Clone the Repository
\`\`\`bash
git clone https://github.com/yourusername/ai-expense-tracker.git
cd ai-expense-tracker
\`\`\`

### 2. Database Setup (Supabase)
1. Create a new project on [Supabase](https://supabase.com).
2. Navigate to the SQL Editor and run the following schema:

\`\`\`sql
CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  email VARCHAR(255) UNIQUE NOT NULL,
  password VARCHAR(255) NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE expenses (
  id SERIAL PRIMARY KEY,
  description VARCHAR(255) NOT NULL,
  amount DECIMAL(10, 2) NOT NULL,
  category VARCHAR(100) NOT NULL,
  date DATE DEFAULT CURRENT_DATE,
  user_id INT NOT NULL REFERENCES users(id) ON DELETE CASCADE
);
\`\`\`

### 3. Backend Setup
1. Navigate to the backend directory:
   \`\`\`bash
   cd backend
   npm install
   \`\`\`
2. Create a `.env` file in the `backend` folder based on the `.env.example`:
   \`\`\`text
   PORT=5000
   DATABASE_URL=your_supabase_transaction_pooler_connection_string
   GEMINI_API_KEY=your_gemini_api_key_here
   JWT_SECRET=your_super_secret_jwt_string
   FRONTEND_URL=http://localhost:5173
   \`\`\`
3. Start the server:
   \`\`\`bash
   npm run dev
   \`\`\`

### 4. Frontend Setup
1. Open a new terminal and navigate to the frontend directory:
   \`\`\`bash
   cd frontend
   npm install
   \`\`\`
2. Create a `.env` file in the `frontend` folder:
   \`\`\`text
   VITE_API_URL=http://localhost:5000
   \`\`\`
3. Start the Vite development server:
   \`\`\`bash
   npm run dev
   \`\`\`

## 🧠 AI Integration Note

This project uses the official `@google/genai` SDK to communicate with the Gemini API. By passing structured JSON data of the user's monthly expenses to the `gemini-3.6-flash` model, it acts as a personalized financial advisor without requiring complex prompt engineering.

## 🌍 Deployment

### Backend (Render)
1. Connect your GitHub repository to Render as a "Web Service".
2. Set the Root Directory to `backend`.
3. Set the Build Command to `npm install` and the Start Command to `npm start`.
4. Add your `.env` variables to Render.

### Frontend (Vercel)
1. Import your GitHub repository into Vercel.
2. Set the Root Directory to `frontend`.
3. Add the `VITE_API_URL` environment variable, pointing it to your deployed Render backend URL (ensure there is no trailing slash).

## 🛡️ Security
*   Passwords are hashed using `bcryptjs` before storage.
*   Sessions are managed via JWT.
*   API keys are secured in the backend and never exposed to the client-side code.
